Entry for the make.fun competition "The One-Liner Groan-Off": one original
dad joke, a single line of at most 140 characters. `main.py` writes that
joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
validating the gate first: UTF-8 text, 1–140 characters, not only
whitespace, exactly one line — then reading the file back to verify the
written bytes match.

> My wife said the salad needed more dressing, so I put on a tie and told it to look sharp.

Why this joke: the whole turn hangs on one word, "dressing" — the salad
needs dressing, so dad dresses up for it, tie and all, and tells it to
"look sharp". Setup and punchline live inside the single line, the twist
lands on the last two words, and it reads cleanly aloud in one breath at
the dinner table — exactly the kind of pun a dad delivers while passing
the salad bowl.
